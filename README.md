# What's in My Fridge?

CSCE 310 project - recipe matching using similarity search and set cover.

Joaquin, Rohan, Sarah, Henry

Given 3-4 ingredients in your fridge, find the recipes that match best. We compare:

- brute force vs inverted index
- Jaccard brute force vs MinHash/LSH
- exact vs greedy set cover (meal planning)

Data: Food.com recipes dataset (Kaggle). Put it in `data/`, it's not committed.

Tasks and deadlines are in the Issues and Milestones tabs.
